## 1. 平台与架构术语

| 术语 | 英文/编码 | 定义 |
| --- | --- | --- |
| OTWB | — | 一体化供应链执行平台：订单（O）+ 运输（T）+ 仓储集成（W）+ 结算（B） |
| 基础资料服务 | MDM | 全局主数据中心，管理贸易伙伴、物料、地址等主数据 |
| 订单管理服务 | OMS | 订单编排与库存可视化服务 |
| 运输管理服务 | TMS | 运输计划与执行服务 |
| 结算管理服务 | BMS | 计费引擎与应收应付结算服务 |
| 集成层 | — | 平台与外部 WMS/ERP/EDI 之间的指令下发与结果回传通道 |
| 租户 | Tenant | 平台的最小商业隔离单位，租户间数据完全隔离 |
| 域 | Domain | 租户内的数据作用范围：PUBLIC 域（全局共享）/ 用户域（域内隔离） |
| 数据字典 | — | 枚举值的统一定义与维护（如下拉选项） |
| 自定义字段 | UDF | 各档案/单据预留的可扩展字段（UDF01~UDF20） |
| OpenAPI | — | 平台对外开放接口，ApiKey 换取 Token 后调用 |

## 2. 主数据术语

| 术语 | 英文/编码 | 定义 |
| --- | --- | --- |
| 贸易伙伴 | Partner | 与本企业发生业务往来的主体：货主、客户、供应商、承运商 |
| 货主 | — | 货物所有权方，仓储业务的主要服务对象 |
| 客户 | — | 下游贸易伙伴：OMS 下单方、TMS 收货对象、BMS 应收主体 |
| 结算客户 | — | 应收费用的实际结算主体；结算客户一定是客户，客户不一定是结算客户 |
| 关联租户 | — | 与本租户建立一对一协同关系的外部 TMS 租户，支持双向委托运输；承运商主数据以"授权租户"字段维护（一个承运商仅可授权一个启用状态的租户） |
| 分仓同步 | — | 主数据（货主/客户/供应商/物料等）向外部 WMS 分仓分发的机制 |
| 收款计划 | — | 挂在客户主数据上的分期收款约定（比例+账期） |
| 物料订货限制 | — | 定义物料与仓库、客户的可订货关系 |
| 物料 | Material | 商品主数据的核心档案：订单、出入库与运输单据的货物对象，记录编码、名称、物料组、规格（长/宽/高/净重）、包装与管控属性（SN 管理、危险品） |
| 物料组 | — | 物料的分类维度，数据字典维护（成品/半成品/原材料/辅料/包装材料等） |
| 包装 | — | 包装主数据档案，定义包装代码、名称与规格，供物料及装箱、装托作业引用 |
| 序列号 | SN | 物料单品级唯一标识；是否SN管理=是的物料在出入库与运输环节按 SN 收发货核对 |
| 危险品标识 | — | 物料的危险货物标记；取值"是"的物料在单据、配载与运单全程展示标识并校验承运资质 |

## 3. 单据术语

| 术语 | 英文/编码 | 定义 |
| --- | --- | --- |
| 采购订单 | PO | 面向供应商的采购指令，与入库订单一对多 |
| 销售订单 | SO | 面向客户的销售指令，与出库订单一对多；来源含手工/Excel/EDI/API/客户门户 |
| 入库订单 | — | OMS 编排的入库执行指令，推送外部 WMS 执行 |
| 出库订单 | — | OMS 编排的出库执行指令，推送外部 WMS 执行，并可联动生成发货订单 |
| 发货订单 | — | TMS 运输需求的载体，记录货物、起止地、费用与计划 |
| 订单分段 | — | 发货订单按运输 leg 拆分的结果，是配载的输入 |
| 配载 | — | 将分段组合为运单并指派承运商、运输方式、设备、司机的计划过程 |
| 运单 | — | 运输执行的单据，承载节点跟踪、签收与回单 |
| 回单 | POD | 签收凭证 |
| 货差 | — | 提货/签收量与计划量的差异，自动触发单据与费用刷新 |
| 凭证 | — | BMS 应收/应付费用单据，由业务事件按规则自动生成 |
| 合并发票 | — | 多张凭证按合并条件（相同结算客户+域+贸易条款+服务级别等）合并为父/子发票结构 |
| 对账单 | — | 按结算主体汇总凭证生成的结算单据，是开票与收付款依据 |
| 实收/实付 | — | 对账单的收款/付款记录，支持部分收付与撤销 |

## 4. 计费术语

| 术语 | 英文/编码 | 定义 |
| --- | --- | --- |
| 费率合同 | — | 与客户（应收）/承运商（应付）约定的计费合同 |
| 计费模式 | — | 费用计算方式：标准（费率明细）/ 按立方 / 按趟次 / 包月 |
| 计费基数 | — | 费用计算的基础量纲：件数/重量/体积/计费重/趟次等 |
| 凭证创建规则 | — | 凭证生成时机的配置：审核/提货/到货/签收等节点触发 |
| 盲对 | — | 对账单生成方与接收方互不可见明细的对账模式 |
| 系数调整 | — | 对账单按系数（如 0.9）对指定费用类型进行的金额调整 |

## 5. 状态通用词

| 术语 | 定义 |
| --- | --- |
| 开放 | 单据创建后的初始可操作状态 |
| 审核 | 单据通过业务校验，进入可执行/可计费状态 |
| 反审核 | 审核的逆向操作 |
| 关闭 | 单据终止，不可再执行（可逆向的关闭须单独定义） |
| 取消 | 单据作废；与关闭的区别在各单据状态机中定义 |
| 启用/停用 | 档案类主数据的可用状态切换 |
| 部分×× | 多行/多段单据部分完成的状态（如部分计划、部分预约、部分收款） |
