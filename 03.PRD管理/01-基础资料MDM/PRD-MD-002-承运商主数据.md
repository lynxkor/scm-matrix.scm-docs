## 2. 功能概述

承运商是 OTWB 平台运输执行与应付结算的核心贸易伙伴主数据，由基础资料服务（MDM）统一管理，一处维护、全服务共用。

**业务定位**：

- 配载生成运单时指派承运商；费率合同、时效合同、运单指派规则按承运商（或承运商组）匹配计费与时效；
- 维护结算信息（结算方式、开户银行、银行账户），供 BMS 应付对账单创建与付款引用；
- 支持授权关联协同租户，实现委托第三方物流运输；
- 支持承运商外部账户登录，仅可见/操作自身承运商数据；
- 承运商类型为快递时，可维护集成快递接口配置，运单可获取面单与跟踪路由。

**核心能力**：承运商新建/编辑/删除/查看详情、启用/停用、授权租户管理、合同附件管理（含批量上传/下载）、分仓同步、导入/导出。

**菜单路径**：基础资料 → 贸易伙伴 → 承运商

## 4. 业务规则与异常处理

| 编号 | 规则/场景 | 处理逻辑 | 异常/提示 |
| --- | --- | --- | --- |
| R-MD18 | 承运商编码唯一 | 承运商编码域内唯一，新建必输承运商编码与承运商名称 | 重复保存提示"承运商编码已存在" |
| R-MD19 | 启用控制 | 是否启用=是的承运商才可在配载、费率合同、指派规则等处选择；停用不影响已引用该承运商的历史单据 | 停用承运商在新单据下拉中不显示 |
| R-MD20 | 集成快递接口配置 | "集成快递接口配置"分区仅当承运商类型=快递时显示，切换为非快递类型时分区隐藏、已维护配置保留但不再生效；维护接口类型与有效扩展参数后，该承运商运单可执行获取面单、路由跟踪获取，跟踪明细写入运单跟踪明细列表 | 未维护或参数无效时不执行路由获取，无报错 |
| R-MD21 | 授权租户 | 一个承运商仅可授权关联一个启用的协同租户；关联后支持将订单委托给该第三方物流运输；多个承运商可分别关联不同租户 | 关联第二个租户时提示"一个承运商只能关联一个租户" |
| R-MD22 | 结算信息引用 | 创建应付对账单时自动带出承运商维护的结算方式；开户银行与银行账户供应付付款单引用 | — |
| R-MD23 | 删除约束 | 承运商未被任何业务单据（发货订单/运单/凭证/对账单/费率合同）引用且未被授权给用户时方可删除，否则仅可停用 | 提示"承运商已被业务数据引用，不可删除，请使用停用" |
| R-MD24 | 承运商授权与账户隔离 | 用户使用承运商需在角色管理→用户管理→承运商权限中授权，授权变更重新登录生效；承运商身份账户登录时，仅能查询、导入、操作自身承运商编码的数据 | 承运商账户导入其他承运商编码数据时提示"无权操作该承运商" |
| R-MD25 | 批量合同附件命名 | 批量上传文件名格式：`承运商编码+文件名.文件类型` 或 `承运商编码(文件名).文件类型`；文件按承运商编码匹配挂接至合同附件 | 命名不合法时该文件上传失败并提示命名规则 |
| R-MD26 | 分仓同步 | 承运商新建保存后，需执行分仓同步才在外部仓储系统分仓显示 | 同步成功提示"仓库承运商信息同步成功" |

## 5. 权限与审计说明

### 5.1 角色与操作权限

| 角色 | 承运商主数据操作权限 |
| --- | --- |
| 主数据管理员 | 新增、编辑、删除、启用/停用、分仓同步、合同附件与批量附件上传/下载、导入、导出、授权 |
| 订单客服（OMS）/调度（TMS）/结算员（BMS） | 查询、查看详情（仅已授权承运商） |
| 承运商账户（外部协同登录） | 仅自身承运商编码数据的查询与被授权的操作（如附加费录入、运单反馈）；导入仅限自身承运商编码（R-MD24） |
| 系统管理员 | 全部权限，含 PUBLIC 域数据维护 |

### 5.2 数据权限

- 承运商数据按"域 + 用户已授权承运商"双重过滤（R-MD24）；
- 承运商授权在角色管理→用户管理→承运商权限中设置，支持批量授权，变更后重新登录生效；
- 承运商身份账户登录时数据按自身承运商编码隔离。

### 5.3 审计

- 承运商新建、编辑、删除、启用/停用、分仓同步、合同附件与批量附件上传/下载、导入、授权操作均记录操作人、操作时间与变更前后值；
- 删除为逻辑删除，保留档案以供历史单据追溯。
