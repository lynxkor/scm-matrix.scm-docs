# 业务流程图 Visio 绘制规范

> 文件定位：本文件规定 OMS / TMS / BMS 业务流程图在 Visio 中的**版面分区、图形元素规格、序号样式、文字、连线、颜色、组合与图层**等绘制规则。
>
> 版本说明：V1.0（2026-11-24）首次成文，依据 `01.需求管理/01.流程图管理/TMS零部件板块返空流程-业务流程_V1.0.vsdx` 的实际样式反向整理，只抽取样式与规则，不含业务内容。与《业务蓝图格式标准.md》第五节"图示规范"配套使用：蓝图正文用 mermaid 表达，正式流程图以本文件为准。

---

## 一、适用范围

| 项 | 说明 |
|---|---|
| 适用对象 | 业务流程图（泳道式横向流程图），含端到端流程与分支流程 |
| 不适用 | 组织架构图、系统架构图、界面原型（见《产品原型设计规范.md》） |
| 工具 | Microsoft Visio（.vsdx） |
| 基准样例 | 返空流程 V1.0（4 条泳道、3 个阶段、11 个步骤） |

所有坐标以**英寸（in）**为单位，原点为**页面左下角**：X 自左向右递增，Y 自下向上递增。

## 三、页面与版面坐标

### 3.1 页面设置

| 项 | 值 |
|---|---|
| 纸张 | A3 横向（Visio 页面 16.035 × 11.693 in） |
| 方向 | 横向，单页 |
| 背景页 | 无 |
| 内容占位 | 图形区间 Y = 0.32 ~ 8.23 in（上方留白，导出时按内容裁切） |

### 3.2 版面分区

| 分区 | X 范围 | Y 范围 | 尺寸 |
|---|---|---|---|
| 标题条 | 2.35 – 10.35 | 7.775 – 8.225 | 8.00 × 0.45 |
| 阶段条 | 1.30 – 11.41 | 7.33 – 7.63 | 每段 3.37 × 0.30 |
| 泳道区 | 0.30 – 11.42 | 0.82 – 7.32 | 11.12 × 6.50 |
| ├ 角色列 | 0.30 – 1.30 | 随泳道行 | 1.00 × 行高 |
| └ 任务区 | 1.30 – 11.42 | 0.82 – 7.32 | 10.12 × 6.50 |
| 备注条 | 0.30 – 11.42 | 0.32 – 0.74 | 11.12 × 0.42 |

- 标题条水平中心 = 任务区中心（X = 6.35），不得按整页居中。
- 阶段条三等分任务区宽度（1.30 / 4.67 / 8.04 / 11.41），段宽一致。
- 备注条与泳道区同宽，紧贴页面底部，与泳道区间距 0.08 in。

### 3.3 泳道行

泳道自上而下按"流程发生顺序"排列角色，行高按该角色的活动量分配（成员固定为 1.35，主力角色可加高）。

| 行序 | 角色 | Y 范围 | 行高 |
|---|---|---|---|
| 1 | 司机 | 5.97 – 7.32 | 1.35 |
| 2 | 系统 | 3.77 – 5.97 | 2.20 |
| 3 | 现场返空人员 | 2.42 – 3.77 | 1.35 |
| 4 | 门卫 | 0.82 – 2.42 | 1.60 |

- 角色名过长（如"现场返空人员"）允许自动换行，不得缩字号迁就。
- 角色列宽度固定 1.00 in，文字 12pt 加粗居中。

### 3.4 任务列

| 列 | 对应阶段 | 中心 X | 左右边界 | 宽 |
|---|---|---|---|---|
| 1 | 阶段01 | 2.98 | 1.53 – 4.43 | 2.90 |
| 2 | 阶段02 | 6.35 | 4.90 – 7.80 | 2.90 |
| 3 | 阶段03 | 9.84 | 8.39 – 11.29 | 2.90 |

- 任务框宽固定 2.90 in，一律以列中心对齐（PinX = 列中心）。
- 列间净距 0.47 / 0.59 in，不得小于 0.45 in（留给折线走位）。
- 同列相邻框垂直净距 0.11 – 0.20 in；跨阶段下移时仍保持列中心不变。
- 节点在泳道内垂直居中或按连线需要微调，但同一列内保持自上而下的先后顺序。

## 四、图形元素规格

### 4.1 规格总表

| 元素 | 尺寸 (in) | 填充 | 描边 | 文字 |
|---|---|---|---|---|
| 标题条 | 8.00 × 0.45 | #FFFFFF | 0.25 pt #000000 | 12 pt 粗体 #000000，2 行居中 |
| 阶段条 | 3.37 × 0.30 | #FFFFFF | 0.25 pt #000000 | 12 pt #000000 居中 |
| 泳道角色格 | 1.00 × 行高 | #FFFFFF | 0.25 pt #000000 | 12 pt 粗体 #000000 居中 |
| 泳道行 | 11.12 × 行高 | #FFFFFF | 0.25 pt #000000 | 无文字 |
| 任务框（流程 / 矩形） | 2.90 × 0.55 | #FFFFFF | 0.25 pt #000000 | 8 pt #000000 居中，行距 120% |
| 序号条 | 2.90 × 0.20 | #F2F2F2 | 0.25 pt #404040 | 8 pt #404040 居中 |
| 开始 / 结束 | 1.20 × 0.40（结束 1.20 × 0.30） | #FFFFFF | 0.75 pt #000000 | 8 pt #000000 居中 |
| 文档节点 | 2.90 × 0.70 | #FFFFFF | 0.75 pt #000000 | 8 pt #000000 居中 |
| 备注条 | 11.12 × 0.42 | #FFFFFF | 0.25 pt #000000 | 12 pt #000000 居中 |
| 连接线 | — | — | 1.00 pt #156082 | 末端实心箭头 |

字号只有两档：**结构文字 12 pt（标题/阶段/角色/备注），业务文字 8 pt（任务框、序号、起止节点）**。

### 4.2 框架类元素

| 元素 | 规则 |
|---|---|
| 标题条 | 第 1 行 `流程名（V版本 · YYYY-MM-DD）`，第 2 行一句话说明流程范围；粗体、居中、两行 |
| 阶段条 | 格式 `阶段NN · 阶段名`，NN 两位（01、02、03），段数与任务列一一对应 |
| 泳道行 | 一张图只表达一个业务流程；跨流程共用元素时另起一页，不得横向无限延展 |
| 备注条 | 第 1 行写异常/兜底口径，第 2 行写调研控制点或待确认项，两行均以 12 pt 居中 |

### 4.3 任务框与序号条（核心样式）

每个业务步骤是**一个组合**，由「框体 + 序号条」两部分组成：

```
┌──────────────────────────────┐   ← 组合：任务框<序号>
│             006              │   ← 序号条 2.90 × 0.20，填充 #F2F2F2，线 #404040
├──────────────────────────────┤   ← 分隔线即序号条下边框
│        系统显示返空清单       │   ← 框体正文 8 pt 居中
│      终端展示容器与数量明细    │
└──────────────────────────────┘
        框体 2.90 × 0.55，填充白，线 0.25 pt 黑
```

| 参数 | 值 |
|---|---|
| 序号条宽 | 与框体等宽（2.90 in） |
| 序号条高 | 0.20 in |
| 序号条位置 | 上沿与框体顶边对齐；PinY = 框体中心 Y + 框体高/2 − 0.10 |
| 序号条填充 | #F2F2F2 |
| 序号条描边 | 0.25 pt #404040（四边都画，下边框充当分隔线） |
| 序号条文字 | 8 pt #404040，水平居中，垂直居中，四边距 0 pt |
| 框体正文上边距 | 0.21 in（= 序号条 0.20 + 0.01 间隙） |
| 框体正文下边距 | 0 in；左右边距 2 pt |
| 框体正文对齐 | 水平居中、垂直居中、行距 120% |
| 文档节点 | 框高 0.70 in（波浪底会吃掉文字区），正文上边距 0.21 in、下边距 0 |

要求：

1. 序号条必须与框体**组合**后使用，组名 `任务框<序号>`，序号条命名 `序号<序号>`。
2. 不允许缩放整个组合（缩放会改变序号条高度）；调整尺寸时分别改框体与序号条。
3. 序号条只能贴在框体顶部，不得悬浮在框外或穿过框线。
4. 框内文字从第 1 行起就写在框体里（不含序号），序号不得出现在正文。

### 4.4 开始 / 结束节点

- 使用 Visio "开始/结束" 母版（胶囊形），开始 1.20 × 0.40 in、结束 1.20 × 0.30 in，描边 0.75 pt 黑。
- 文字固定为"开始""结束"，8 pt，不加序号、不加说明。
- 开始节点位于第一条泳道起点列，结束节点位于最后阶段列的末端。

### 4.5 文档类节点

- 使用 Visio "文档" 母版（波浪底），2.90 × 0.70 in，描边 0.75 pt 黑。
- 因波浪底占用底部空间，框高比普通任务框高 0.15 in；正文下边距设为 0，避免文字压到波浪线。
- 序号条规格与普通任务框一致（等宽、0.20 高、贴顶）。

## 五、编号规范

| 规则 | 要求 |
|---|---|
| 位数 | 固定 3 位数字，从 001 起 |
| 连续性 | 连续、不跳号、不复用；删除步骤后不重排后续编号 |
| 排序 | 按主流向：阶段列自左向右、同列自上而下；跨泳道往返的执行节点（如承运商接单）按流向编号，允许其高度顺序与编号不同 |
| 出现位置 | 只出现在序号条内；任务框正文首行不再重复序号 |
| 与蓝图的对应 | 若流程图对应蓝图场景卡，序号须与《业务蓝图格式标准》3.3 活动步骤编号（010 起、步长 10）保持一致；两者不同时须在场景卡中给出映射关系 |
| 分支 | 判断/异常不另给序号；需要表达时走备注条或子流程 |

## 六、文字规范

| 位置 | 规则 | 示例 |
|---|---|---|
| 任务框第 1 行 | 动作短语，动词开头，≤ 12 字；括号补充条件/结果 | 卸货完成（系统确认） |
| 任务框第 2 行 | 关键对象或状态，多项用 ` · ` 分隔，≤ 18 字；只有一步时可省略本行 | 收货确认 · 容器置为待返空 |
| 阶段条 | `阶段NN · 阶段名` | 阶段02 · 到场与装车 |
| 标题条 | 2 行：流程名（V版本 · 日期）+ 一句话范围 | 返空业务流程（V1.0 · 2026-11-20） |
| 泳道角色 | 业务角色名（岗位口径），不加部门前缀 | 司机 / 系统 / 现场返空人员 / 门卫 |
| 备注条 | 第 1 行异常口径；第 2 行调研控制点，` ｜ ` 分隔 | 备注：…；调研控制点：… |

通用要求：

- 字体：沿用 Visio 主题字体（西文 Calibri，中文回退系统黑体）；需跨机器一致时显式设为"微软雅黑"，字号只取第四节的两档。
- 中文全角标点；分隔符 ` · `、` ｜ ` 两侧各留一个半角空格，全图统一。
- 框内文字不加句号，不使用首行缩进。
- 换行必须使用**真实换行符（CRLF）**，不得把 `\n` 当作字面量写进文字。
- 同一概念全图只用一种叫法；系统名用代码（TMS / OMS / BMS）。

## 七、连线规范

| 项 | 要求 |
|---|---|
| 走向 | 主流程自上而下；跨列用直角折线（竖—横—竖），横段保持水平 |
| 线宽/颜色 | 1.00 pt，#156082 |
| 箭头 | 仅终点带箭头，实心三角；起点无箭头 |
| 吸附 | 两端吸附到**框体**（不得吸附序号条）；进入目标框时落在上边或左边中点 |
| 入线直段 | 箭头前保留 0.10 – 0.20 in 直线段，避免箭头压在框线上 |
| 竖线位置 | 保持在任务列中心（X = 2.98 / 6.35 / 9.84）穿过泳道 |
| 折点 | 固定折点，关闭自动绕行；同一路径不得混用连接线与手绘线段 |
| 手绘线段 | 确需手绘时，样式必须与连接线一致（1.00 pt、#156082、同款箭头） |
| 异常路径 | 虚线表示兜底/异常，并在备注条说明；无异常分支时不画虚线 |

## 八、颜色规范

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 / 主体填充 | #FFFFFF | 所有框体、泳道、标题、备注 |
| 文字 / 框线 | #000000 | 主体文字与 0.25 pt 边框 |
| 序号条底 | #F2F2F2 | 仅序号条使用 |
| 序号文字 / 序号条线 | #404040 | 序号比正文弱一档的灰 |
| 连接线 | #156082 | 全图唯一彩色，仅用于连线与箭头 |

原则：**黑白灰为主，仅连接线使用品牌蓝**；不使用彩色填充区分角色或阶段（与早期彩色版本区分，彩色仅用于汇报插图，不作为交付源文件）。

## 九、组合、图层与命名

| 图层 | 内容 |
|---|---|
| 流程图 | 标题条、阶段条、泳道、任务框组合、开始/结束节点、文档节点、备注条 |
| 连接线 | 全部连接线与手绘箭头段 |

规则：

- 所有图形必须挂图层，便于整体显示/隐藏、锁定与打印控制；不允许"无图层"图形。
- 组合（任务框）加入「流程图」图层即可，子形状随组合管理。
- 命名：组合 `任务框001`…；序号条 `序号001`…；框体保留母版名（流程/矩形/文档）。
- 修改文字时进入组合内双击框体，不要直接改组合文字（组合文字为空）。

## 十、绘制与修改操作要点（易错点）

| # | 易错点 | 正确做法 |
|---|---|---|
| 1 | 多行文字写成 `\n` 字面量，图上出现反斜杠 | 使用真实 CRLF 换行 |
| 2 | 文字透明度被误设为 1（Char 行第 17 格 ColorTrans） | 保持 0；该错误在部分渲染工具中看不出来，必须直接查单元格值 |
| 3 | 序号条与框体分开移动，图面错位 | 先组合再移动、复制 |
| 4 | 组合后未加入图层，隐藏图层时序号条残留 | 组合后立即挂「流程图」图层 |
| 5 | 缩放整个组合，序号条被压扁 | 分别改框体与序号条尺寸 |
| 6 | 文档节点改高后文字压到波浪底 | 重新设上边距 0.21 in、下边距 0 |
| 7 | 连线吸附到序号条上，箭头指向灰条 | 吸附点改为框体上边/左边 |
| 8 | 手绘线段颜色与连接线不一致（黑色混入） | 统一 1 pt / #156082 |
| 9 | 直接改源文件无备份 | 结构性改动前先复制备份 |
| 10 | 改完只做局部截图确认 | 导出整页 PNG（长边 2000 px）复核 |
